# مواصفة المرفقات (رفع ملفات وصور من الجهاز) — سجلي

## الواقع التقني
- Cloud Storage for Firebase يتطلب خطة Blaze (بطاقة) للمشاريع الجديدة؛ المشروع على الخطة المجانية، ومحاولة إنشاء الحاوية رُفضت ببطاقة غير موجودة. لذلك تُخزَّن المرفقات **داخل Firestore** كبيانات base64 مضغوطة (حد المستند 1 MiB) مع ضبط الحجم، وهذا يكفي للصور وملفات PDF الصغيرة. الخيار الأكبر لاحقاً: Cloudflare R2 (10GB مجاناً) عبر Worker إن أراد صاحب المشروع تفويض حسابه.

## نموذج البيانات
`files/{id}` (id = shortId): `{ n: الاسم, t: النوع (image/jpeg | image/png | application/pdf | audio/mpeg), sz: الحجم بالبايت, d: base64 (بلا بادئة data:), scope: 'lesson'|'student'|'school'|'comm'|'profile', ref: {code?, wk?, cid?, si?, tid?}, tid, tn, ts }`.
- قاعدة Firestore: قراءة لأي مسجّل؛ إنشاء لأي مسجّل بشرط `id.matches('^[a-z0-9]{4,12}$')` و`stamped()` و`d is string && d.size() <= 950000` و`t in ['image/jpeg','image/png','image/webp','application/pdf','audio/mpeg','audio/mp4']` و`keys().hasOnly(['n','t','sz','d','scope','ref','tid','tn','ts'])`؛ حذف لأي مسجّل (الحذف يُظهر تأكيداً في الواجهة ويقتصر على صاحب الملف أو المدير).
- فهرس خفيف `filesidx/{tid}`: `{ list: [{id, n, t, sz, scope, ref, ts}], tn, ts }` لتجنب تنزيل كل الملفات عند العرض (القوائم تقرأ الفهرس فقط، والمحتوى عند الفتح).
- سعة: كل ملف ≤ 700KB بعد الضغط؛ الصور تُصغَّر في المتصفح إلى 1280px بجودة 0.72 (canvas) قبل الرفع؛ PDF > 700KB يُرفض برسالة «الملف كبير — اضغطه أو شاركه رابطاً»؛ حصة شهرية لكل معلم 40 ملفاً (تُحسب من الفهرس) مع عدّاد ظاهر.

## المكوّن المشترك `SIJIL_FILES.attach(opts)`
- زر «📎 إرفاق» يفتح `<input type="file" accept="image/*,application/pdf,audio/*" multiple>` — على الجوال يسمح بالكاميرا مباشرة (`capture` عند اختيار «📷 التقاط صورة»).
- معاينة قبل الرفع (صورة/اسم PDF/حجم بعد الضغط)، شريط تقدم، ثم بطاقة مرفق: صورة مصغّرة أو أيقونة PDF/صوت + الاسم + الحجم + أزرار: فتح (نافذة/تبويب)، مشاركة واتساب (رابط عرض عام `v/?f={id}`)، حذف.
- صفحة عرض عامة `v/index.html?f={id}` (مثل w/) تعرض الملف لأولياء الأمور بلا تسجيل (App Check + مصادقة مجهولة كما في w/).

## أين يظهر (أفضل المواضع)
### المعلم
1. **الدرس** (صفحة الدرس والحصة الحية): «📎 مرفقات الدرس» — صور السبورة، عرض PDF، ورقة إضافية؛ تُعرض على السبورة في الحصة الحية (`data-v="lesson"`) وتُرسل للطلاب مع الورقة التفاعلية كمرفق اختياري.
2. **بطاقة الطالب**: «📎 أدلة وأعمال» — صورة واجب/عمل الطالب أو شهادة؛ تظهر لولي الأمر في رسالة واتساب كرابط عرض.
3. **سجل التواصل**: إرفاق إشعار موقّع/صورة مع المراسلة.
4. **بنك أوراق العمل**: «⬆️ ورقة من جهازي» (PDF/صورة) تُرسل للطلاب برابط عرض عندما لا تُناسب الورقة التفاعلية.
### المدير
5. **⚙️ الإدارة → 🗂️ مكتبة المدرسة**: مستندات لكل المعلمين (الجدول الرسمي، الخطة التشغيلية، النماذج، التعاميم) مع تصنيف وبحث، وتظهر للمعلمين في «المزيد → مكتبة المدرسة».
6. **التعاميم والمهام**: مرفق مع كل تعميم.
7. **هوية المدرسة**: شعار المدرسة (صورة) يظهر في رأس كل المستندات المطبوعة وفي شاشة الدخول؛ وتوقيع/ختم المدير للشهادات (اختياري).
8. **الزيارة الصفية**: صورة أو ملاحظة مصورة.
9. **بطاقة المعلم** (المدير): مرفقات خاصة بالمعلم (قرار، تكليف).

## القبول
- رفع صورة 4MB من الجوال → تُضغط إلى ≤ 700KB خلال ≤ 3 ثوانٍ وتظهر في بطاقة الطالب وفي رابط العرض العام بلا تسجيل.
- رفع PDF 500KB في مكتبة المدرسة → يظهر لكل المعلمين في «المزيد» ويُفتح على الجوال.
- PDF 3MB → رسالة رفض واضحة.
- الحذف يزيل الملف والفهرس، والحصة الشهرية تُعرض وتُحترم.
