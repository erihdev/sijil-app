# مواصفة قناة الرسائل الخاصة — سجلي

## المطلوب
- المعلم يرسل إلى حساب الطالب وولي أمره: **مستوى الابن في مادتي**، **استدعاء**، شكر، تنبيه واجب،
  تنبيه سلوك، أو نصاً حراً — لا في قروب واتساب بل في حساب الطالب نفسه.
- الطالب يرى **إشعاراً** بوصول واجب أو رسالة، ثم يدخل حسابه ليرى التفاصيل.
- ولي الأمر يرى **مستوى ابنه كاملاً** لا بطاقات مختصرة، و**تقييمه لحظياً** أثناء اليوم وفي نهايته.

## لماذا لا تكفي المسارات القائمة
- `comms/{tid}_{cid}` سجلُّ تواصل المعلم مع البيت، ويُقرأ **بمطالبة معلم** — لا يصل الطالب.
- `assignidx/{cid}` فهرس أوراق الفصل كله: لا يصلح للاستدعاء ولا لمستوى ابنٍ بعينه (يقرؤه كل طلاب الفصل).
- مستند الفصل مقروء لأي جهاز مجهول — فأي شيء شخصي فيه مكشوف (وهو ما أُصلح بنقل الجوالات إلى `sedits`).

## مفتاح الرسائل mk — كيف تُخصَّص القراءة لطالب واحد
البوابة تفتح بحساب **مجهول**: القواعد لا تعرف من الطالب، والدخول إنما يُثبت بمعرفة رقم الهوية
(بصمة `spins/{sha256(الهوية|الفصل|الملح)}`). فالقاعدة نفسها تُستعمل للرسائل:

- عند تسجيل الهويات تُولّد لوحة المدير لكل طالب **مفتاحاً عشوائياً** `mk` (٢٤ محرفاً) ويُخزَّن:
  - في `spins/{h}.mk` — لا يعرفه إلا من يعرف رقم هوية الطالب (البصمة `get` مسموح و`list` ممنوع).
  - في `mkeys/{cid}.k["<si>"]` — فهرس للمعلمين، قراءته بمطالبة معلم فقط.
- `smsg/{mk}` صندوق الطالب: `get` مسموح لأي مصادَق (فمن لا يعرف mk لا يجده)، و`list` **ممنوع**،
  والكتابة بمطالبة معلم. فالطالب يقرأ صندوقه وحده، ولا يقرأ صندوق زميله ولو خمّن الفهارس.
- `sack/{mk}` إشعار القراءة: يكتبه جهاز الطالب (يعرف mk) بشكلٍ مقيَّد — فلا يمسّ نصّ الرسائل.

## نموذج البيانات
```
mkeys/{cid} = { k: { "<si>": "mk…" }, n, tn, ts }          // فهرس المعلمين — قراءة بمطالبة معلم
spins/{h}   = { cid, si, ts, mk }                          // كما هو + المفتاح
smsg/{mk}   = { list: [ msg ], n, ts }                     // صندوق الطالب — get فقط، لا list
  msg = { i:"m1a2b3", k:"level|call|thanks|hw|beh|free", t:"عنوان", b:"النص",
          tid, tn, subj, ts, when? }                       // when: موعد الاستدعاء
sack/{mk}   = { seen: { "<msgId>": ts }, ts }               // قرأها الطالب/وليّه
```
حدود: `list` ≤ ٦٠ رسالة (تُسقط الأقدم)، `t` ≤ ٨٠ محرفاً، `b` ≤ ٧٠٠، والقائمة **تنمو ولا تنقص**
(كما في `comms` و`filesidx`) فلا يمحو أحدٌ صندوق طالب بكتابة واحدة.

## واجهة المعلم
من بطاقة الطالب ومن قائمة الفصل: **«✉️ رسالة لحساب الطالب ووليّه»** بستة قوالب:
| القالب | ما يُولَّد تلقائياً |
|---|---|
| 📊 مستوى ابنكم في مادتي | الدرجة المرصودة والفعلية · النسبة والمستوى · الحضور · الواجبات · المشاركة · السلوك · الترتيب |
| 📣 استدعاء لمقابلة | اليوم والحصة (من جدول المعلم) + سبب مختصر |
| 🌟 شكر وتقدير | أبرز ما تميّز فيه هذا الأسبوع |
| 📚 لم يحلّ الواجب | عدد الواجبات غير المحلولة وآخر ورقة |
| ⚠️ تنبيه سلوك | السلوك المرصود وتاريخه |
| ✍️ نص حر | — |

كل قالب يُعرض **قابلاً للتعديل قبل الإرسال**، ويُسجَّل في `comms` كما هو اليوم (فلا يفقد المعلم سجلّه)،
ومعه زر الواتساب لمن يريد الطريقين. وإرسالٌ لعدة طلاب بضغطة (كل الفصل · المتعثّرون · الغائبون اليوم).

## واجهة الطالب ووليّه
- **📬 صندوق الرسائل**: شارة بعدد غير المقروء على تبويب البوابة، وفتحُ الرسالة يكتب `sack`.
  رسالة الاستدعاء تُبرز بلونٍ وتاريخٍ ظاهر، ورسالة المستوى تُعرض جدولاً لا نصاً مسطّحاً.
- **👨‍👩‍👦 شاشة وليّ الأمر الكاملة**: لكل مادة (المعلم · الدرجة/الفعلية · النسبة · المستوى · الحضور ·
  الواجبات · الأوراق · السلوكيات · الترتيب)، ورسمٌ للأسابيع الأربعة الأخيرة، وتنبيهاتٌ صريحة.
- **اليوم لحظياً**: حصص اليوم من الجدول، ولكل حصة حالة الحضور والمشاركة والواجب والسلوك كما رصدها
  المعلم — تتحدّث **بلا إعادة تحميل** (`onSnapshot` على مستندات رصد معلمي الفصل)، وفي آخر اليوم
  يُعرض ملخّص اليوم كاملاً وزر إرساله للواتساب.

## القبول
1. معلم يرسل «استدعاء» لطالب: يظهر في حساب ذلك الطالب وحده، ولا يظهر لزميله في الفصل نفسه ولو
   قرأ الشبكة بنفسه (اختبار مباشر على القواعد: `smsg/{mk}` لطالبٍ آخر ⇒ مرفوض، و`list` ⇒ مرفوض).
2. رسالة «مستوى ابنكم» تُطابق ما يراه المعلم في سجله رقماً برقم.
3. شارة غير المقروء تنقص بفتح الرسالة، ولا تعود بعد إعادة التحميل.
4. أثناء الحصة: المعلم يرصد مشاركة ⇒ تظهر في شاشة وليّ الأمر بلا إعادة تحميل.
5. لا رقم هوية ولا جوال في أي مستند تقرؤه البوابة، ولا في أي رسالة.
